# CAPEX Dashboard 2027 & Business Plan 2027–2031

Interactive dashboard (3 tabs: CAPEX Budget 2027, Business Plan 2027–2031, Presentation Deck) served via Streamlit.

- `dashboard.html` – self-contained dashboard (Chart.js + Datalabels inlined)
- `app.py` – Streamlit wrapper

Run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```
